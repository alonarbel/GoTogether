🔄 Key User Flows

🔐 Sign Up

1
Register email/password
2
DB trigger creates profile row
3
JWT stored in session
4
AuthContext updates app state

🗺️ Create Card

1
Fill form (type, location, dates, min/max)
2
Upload images → Storage bucket
3
Insert travel_card row
4
If role=traveler → auto-join as participant

🙋 Join Event

1
View card detail page
2
Click Join
3
Insert participants row
4
Participant count updates live

🗑️ Card Expiry

1
Any user loads card list
2
cleanup_expired_cards() RPC fires
3
Future cards past min_deadline → deleted
4
Past events (event_date < today) preserved

⭐ Review

1
Must be a participant
2
Rate card + organizer (1–5 stars)
3
Visible on organizer's public profile
